# 导入清单 · 瓦雷莎的果园救急

把 `_sandbox/default_import_file/` 整个目录导入沙箱（保持目录名）。

| # | 脚本 | 作用 |
|---|---|---|
| 1 | `game.lua` | 主入口：7 层容器、屏幕状态机、信号收发、按键 |
| 2 | `config.lua` | 参数唯一真源：DEFAULT_* + 果园配色 + 50 关 + 5 张教学卡 + 3 页手册 |
| 3 | `state.lua` | 全部运行期状态字段 |
| 4 | `utils.lua` | 控件 / 容器 / 文本 / 命中区 / 拖拽绑定 + 自动提层 |
| 5 | `anim.lua` | 逐帧补间引擎（缓动 / tag / isBusy） |
| 6 | `fx.lua` | 果汁粒子池 + 补间 + 缓动 |
| 7 | `scene.lua` | 果园背景：天空 / 远山 / 草坡 / 太阳 / 飘叶 |
| 8 | `map.lua` | ★ 果园地图选关：横向长图、拖拽、箭头、金圈、吉祥物 |
| 9 | `mascot.lua` | ★ 吉祥物「小果龙」：96×96 纯矩形拼图（_gen_mascot.py 生成） |
| 10 | `guide.lua` | ★ 教学卡与玩法手册（一图两句话） |
| 11 | `hud.lua` | 游玩期极简 HUD |
| 12 | `winUI.lua` | 胜利结算演出：暗星 → 魔环点亮 → 闪光 + 彩带 / 星尘 |
| 13 | `signal.lua` | ★ 与节点图对接的唯一接口（服客 4 条 + 客服 1 条） |
| 14 | `puzzle.lua` | 5×6 棋盘纯计算（校验 / 调试对账用） |
| 15 | `fadeScreen.lua` | 黑幕过渡（淡入淡出） |
| 16 | `transition.lua` | ★ 全屏转场：天地撕开（天空向上 / 地面向下） |
| 17 | `audio.lua` | 音效封装 |

## 挂载与参数

1. `game.lua` 挂在**客户端控件容器**的容器节点上；
2. 脚本参数：`rectPrefabId`（必填）、`cursorPrefabId`（必填）、`textPrefabId`（可选）、`containerPrefabId`（建议填）、`circlePrefabId`（强烈建议：云朵 / 果实 / 太阳 / 圆角四角，不配全变方块）、`ringPrefabId` / `trianglePrefabId` / `star4PrefabId` / `star5PrefabId`（可选，金圈 / 风车叶片与小草 / 装饰星）、三个音效 ID（可选）；
3. 节点图侧实现 `信号协议.md` 里的 6 条信号。
