# 皮耶罗：赴死 · 千星奇域客户端 Lua 工程

> 玩法母本：**level-devil / FableDevil**（30 关手写陷阱的「rage platformer」）。
> **第一阶段 = 原版逐项复刻**：关卡数据、物理常量、陷阱参数全部沿用原版数值，
> 全部用**图元**（纯色矩形 + 文本框）绘制，不依赖任何图片资源。
> 第二阶段（原神元素 UI 包装）只改 `config.lua` 的配色 / 文案 / `COMIC` 分镜。

---

## 一、玩法

```
菜单（30 关选关 + 不死诅咒开关）
└─ 关卡：从左跑到「门」
   ├─ 死亡 → 不死诅咒生效 → 化成鬼魂 → 漂到安全处按空格复活
   └─ 穿过门 → 献祭演出（动态漫画 4 格 + 伤害数字 3,927,698）→ 下一关 = 下一次轮回
```

- **30 关**，逐关复刻原版 `LEVELS`（关卡名、出生点、门位置、陷阱坐标一一对应）。
- **21 种陷阱**：塌陷地板、弹出尖刺、静止尖刺、落石、压路机、碎裂平台、滑动缺口、
  反向操作区、移动平台、传送带、弹簧、锯片、激光、传送门、按钮、闸门、
  闪烁平台、摆锤、炮台、假门、旁白文字。空心与致死矩形全部照抄原版。
- **鬼魂模式（不死诅咒）默认打开**。开 = 死不了，化成鬼魂漂浮，空格原地复活
  （位置卡在实体/致死区里则复活失败，红闪提示）；关 = 原版的死亡→0.85 秒后自动重开。
- 过关后播「献祭演出」：生死之间 → 愚人之眼 → 解放 → 若娜瓦 3,927,698。
  默认每关都播（= 每次轮回的结算），可用参数 `comic=0` 关掉。

### 操作

| 键 | 作用 |
| --- | --- |
| ← → / A D | 移动 |
| ↑ / W / 空格 | 跳跃（鬼魂模式下 ↑/W = 向上漂浮，空格 = 复活） |
| ↓ / S | 向下漂浮（仅鬼魂模式） |
| R | 重来本关 |
| L | 回菜单 |
| N | 下一关（开发用） |

## 二、模块

```
game.lua        入口：生命周期 / 层级容器 / 关卡流转 / 死亡与鬼魂 / 按键 / 终局结算
config.lua   ★  唯一真源：物理常量、陷阱默认值、配色、文案、30 关关卡数据、COMIC 分镜
state.lua    ★  所有 state.* 字段（含开发用 devwin / devnear）
utils.lua       控件创建 / 配色 / 世界坐标→UI 坐标 / AABB / 自绘按钮（真机坑已根治）
anim.lua        逐帧补间引擎（ease / tag / isBusy）
trap.lua     ★  21 种陷阱的状态机 + 图元外观（update / sols / kills / sync / reset）
level.lua       关卡构建（实体 / 门 / 陷阱 / 旁白）+ 每帧推进 + 实心体与致死区汇总
player.lua      玩家物理（分轴解算 + 子步细分）+ 鬼魂漂浮与复活判定
hud.lua         顶部条 / 关卡名 / 死亡数 / 底部提示 / 死亡与过关大字
menu.lua        标题 + 10×3 选关格 + 不死诅咒开关 + 开始按钮
comic.lua       献祭演出（4 格动态漫画 + 伤害数字滚动，图元占位）
fx.lua          粒子池 / 血渍池 / 震屏
fadeScreen.lua  黑幕过渡
audio.lua       音效（ID ≤ 0 静默跳过）
```

`require` 一律带导入根：`require("default_import_file/config")`。

## 三、坐标系（本工程最关键的一条约定）

原版是 960×540、**y 轴向下**、重力为正。为了能**原样照抄 30 关的关卡数据**，
本工程保留了这套坐标系，只在渲染层翻转一次：

```
utils.toUIX(x) = x - 480
utils.toUIY(y) = 270 - y
```

- 设计基准 = 世界尺寸（1 世界像素 = 1 设计像素），整层再用 `k = min(cw/960, ch/540)` 缩放。
- **陷阱 / 玩家 / 碰撞全部算世界坐标**；只有 `sync()` 里换成 UI 坐标。
- 抛物线、跳跃高度、受伤盒这些数值因此与原版完全同量纲，改关卡时可以直接照抄原版。

## 四、装配参数

挂到**客户端控件容器的容器节点**上。

| 参数 | 元件 | 必填 |
| --- | --- | --- |
| `rectPrefabId` | 纯色矩形（图片控件） | ★ 所有图元都靠它染色 |
| `textPrefabId` | 文本框 | ★ 没有它一个字都不显示 |
| `cursorPrefabId` | 光标检测区域 | ★ 没有它菜单点不动 |
| `containerPrefabId` | 容器节点 | 建议配（模拟器的命中测试只下钻真容器） |

音效（可选）：`clickAudioId` / `jumpAudioId` / `deathAudioId` / `winAudioId` /
`popAudioId` / `openAudioId`。

开发用参数：`ghost=0/1`（不死诅咒，默认 1）、`comic=0/1`（演出，默认 1）、
`start=N`（直接进第 N 关）、`devwin=秒`（进关 N 秒后自动过关）、
`devnear=1`（进关时把玩家直接放到门前，验证「走到门→过关」）。

## 六、图元化的取舍（与原版的差异）

| 原版画法 | 本工程 | 说明 |
| --- | --- | --- |
| canvas 路径绘制三角形尖刺 | 45° 旋转的小方块（菱形） | 高度仍按 `size` 对齐，致死盒完全一致 |
| 圆形传送门 / 摆锤圆头 | 两层菱形 | 外圈半透明 + 内芯实色 |
| 圆形擦除转场 | 全屏黑幕淡入淡出 | 引擎没有圆形遮罩 |
| 落石碎成多块 | 单块下落 + 抖动 | 少建控件 |
| 26 粒血花 + 无限血渍 | 44 个控件池 + 24 个血渍池 | 复用不销毁，避免真机抖动 |
| DOM HUD（在画布之外） | 顶部半透明条 + 文本 | **必须加底条**：第 4/13/14/15/17/21/24/26/27/30 关顶部就是浅色实体，不加底条关卡名会看不见 |
| 死亡后 0.85 秒自动重开 | 同（`ghost=0` 时） | 鬼魂模式开启时不重开，改为复活 |

**另外两处有意偏离**（都是为了让「不死诅咒」这套叙事成立）：
1. 鬼魂模式下**死亡数照样 +1**（原版作弊态不计数）。轮回的献祭叙事需要这个数。
2. 鬼魂模式下陷阱**定格**（原版如此）—— 复活后陷阱会接着之前的状态继续走。

## 七、第二阶段的接口（原神元素包装）

只改 `config.lua`，玩法代码不用动：

| 要改的东西 | 位置 |
| --- | --- |
| 整体配色 | `DEFAULT_PALETTE`（`ink` = 平台/实体色、`accent` = 门与强调、`danger` = 致死） |
| 关卡名文案 | `LEVELS[i].name` |
| 死亡吐槽 / 终局评语 | `DEATH_LINES` / `ROASTS` |
| 献祭演出分镜 | `COMIC.panels`（每格 `caption` + `bg` + `actors`） |
| 伤害数字 | `COMIC_DAMAGE` |

`comic.lua` 的 `spawnShape` 支持 `door / harlequin / eye / zonava / glow / burst` 六种
图元剪影；换参考图时把 `actors[i]` 换成图片 prefab 即可，编排（淡入 → 停留 → 换格 →
伤害数字滚动 → 震屏）不用改。

## 八、已知边界

- 只有**键盘 + 鼠标**输入，没做触屏虚拟按键（原版有）。
- 没有存档：死亡数与解锁进度只在本次会话内累计（纯客户端，不依赖服务器）。
- 只有暗色主题（原版有 dark/light 切换）；换主题要重刷全部控件颜色，收益不高。
- 关卡数据是手抄原版，改关卡时建议直接对照 `level-devil/game.js` 的 `LEVELS`。
