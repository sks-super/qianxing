## 2. 装到千星里

1. 新建一个【客户端控件容器】，把这 8 个 `.lua` 都加进工程（**文件名必须保持一致**，
   脚本之间用裸 `require("config")` 互相引用）。
2. 把 **`game.lua` 挂到那个容器节点上**，其余 7 个只作为模块注册、不挂控件。
3. 脚本参数（全可不填，不填就用 `config.lua` 的默认值）：

| 参数 | 默认 | 说明 |
|---|---:|---|
| `rectPrefabId` | `1073741894` | 纯色矩形元件（首选） |
| `imagePrefabId` | `1073741870` | 纯色图片元件（矩形元件拿不到时的回退） |
| `textPrefabId` | `1073741868` | 文本框元件 |
| `containerPrefabId` | `1073741876` | 容器节点元件（4 个分层容器的父） |
| `rectImageId` | 空 | 矩形元件若要求图源，填内置矩形图元 `100001` |
| `tileSize` | `64` | 一格的屏幕边长（px） |
| `heightPx` | `9` | 一级高度的像素高度（崖面刻度） |
| `viewZoom` | `1` | 缩放，`0.5 ~ 3`，**乘在格宽上** |

> ⚠️ 数字参数在真机上**没填会返回 `0`（不是 nil）**，所以本工程一律按
> 「`0` / 空 = 没配 → 用默认值」处理（见 `paramId()`）。

## 4. 玩法要点（都是原版规则，别改）

- 一步一格；**0.25 格高**能踩上去，**0.5 格**踩不上 —— 整套谜题就靠这条。
- 撞树 → 树朝那个方向倒；再撞倒下的树 → 按同向 / 异向**立起**或**侧滑**。
- 漂在水上的木头是**桥**（水面高度 0.25，能踩）；压在陆上的倒木 0.5 格，只能推。
- 两根横木拼一起 → **木筏**；站在筏上会一格一格漂。
- 踩上木牌 → 弹出那段英文原稿的中文译文（`config.DIGRESSION_TEXT`）。

## 6. 渲染怎么搭的（以及为什么这么搭）

- **水不画控件**：整屏一个底色（`containerBg` 里一块 1288×728 的矩形），水面颜色 = `theme.water`。
  原版逐格画水 + 涟漪线，这里省掉 —— 一屏 240 格水，一格一个控件不划算。
- **地形按「窗口」铺**：只铺镜头看得见的那 20×12 格，**跨格才重铺**（`state.winKey` 变才重建），
  格内位移交给容器平移 → 每帧 O(1)。
- **砖缝**：同色同高的一整段先铺一层 `theme.edge`，再把**每一格**内缩 1.4px 的顶面压上去 →
  格子之间自然露出 2.8px 的缝，就是原版「一格一块地砖」的观感。
- **逐格明暗抖动** ±3.5%（`utils.hash2`），原版靠这个做出棋盘感；没有它整片地会糊成一整块。
- **崖面**：原版是竖向三段渐变，这里用三条色带（`wallTop` / `wall` / `shade(wall,-0.3)`）近似。
- **实体**：一个 1×1 容器 + 最多 8 个子图元（影子 / 身体 / 耳朵 / 眼睛 / 脚…），
  **按签名重画**（`type|isl|num|look`），签名不变就只挪容器。
- **绘制顺序**：从南往北画（北边那格的崖面要压住南邻的顶面）；每个图元取用时都 `SetAsLastSibling()`
  —— 真机是「最后一个在最上」，模拟器是「数组下标 0 最后画」，两边等价。
- **实体池顺序**：影子 → 身体 → 眼睛 → 脚，靠 `toLast` 保证后画的盖住先画的。

### 镜头（最容易写错的地方）

`M.focus()` 返回的是**屏幕正中那一点的世界坐标**（`camX`, `camY`），不是视口左上角：

```
屏幕偏移 = (子坐标x - camX, 子坐标y + camY 的相反数)  →  容器位置 = (-camX, -camY)
```

- 世界坐标是 **y 向上**的（行号越大 y 越负），所以 `camY` 是负数，容器要 `-camY` 往上抬。
- 视口窗口 = `camX ± 屏宽/2`、`camY ± 屏高/2`，**别拿 camX 当左上角**——
  写错的表现是「左半屏空、地砖跑到右边」，再错一个符号就是「整屏只剩水」。

| 差异 | 原因 |

| 水没有涟漪线、没有逐格明暗 | 省控件（一屏 240 格水） |

玩法、地图、最短解、木牌文案**与原版完全一致**。

## 8. 踩过的坑（改这个工程前先看）

1. **`math.pow` 在 Lua 5.3 里没有了** → 用 `^`。症状：一开局 `OnUpdate` 每帧报
   `attempt to call a nil value (field 'pow')`，画面卡在上一帧。
2. **`config.OBJ.shadow` 漏定义** → `slot()` 拿不到颜色，真机默认 **纯白**，
   每个物件脚下顶一坨白斑。现在 `slot()` 有兜底，但别依赖它。
3. **`focus()` 的坐标约定必须和 `applyCamera()` / 实体剔除一致**，三个地方一起改。
4. **`take()` 必须 `SetAsLastSibling()`**：控件池是复用的，兄弟顺序会被打乱，
   不压顶就会出现「后画的被先画的盖住」。
5. **`slot()` 每次都重写图元**（`applyImage`）：同一个槽上一帧是圆、这一帧当矩形用时
   不能还是圆的。
6. 地形 / 实体 / 小人**必须在同一个容器**（`containerWorld`）里，容器平移才是镜头；
   `containerBg` 与 `containerHud` 绝不能动。
7. 改完 `.lua` **必须重建就绪存档**再跑模拟器，`--open` 读的是存档里的控件树。
