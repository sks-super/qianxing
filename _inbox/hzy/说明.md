## 4. 改了什么、为什么、怎么验证

### 4.1 `_shared/_check_refs.py`（新增两节校验）

**为什么**：浮岛借木把「元件索引」拆成了三处同源——
`config.DEFAULT_PREFAB_*` ↔ `_tools/_sim_common.mjs` 的 `SIM_TEMPLATE_GUIDS`
↔ `_tools/qxqy_simsave.mjs` 的 `GUID_*`，
再加一份 `编辑器.html` 的 `DEFAULTS` 要跟 `config` 逐项一致。
这四份东西分散在四个文件，**手改必漂移**，所以做成自动校验。

**验证**：见 §6（这条是整批最有力的实证）。

### 4.2 `_tools/_sim_common.mjs` / `qxqy_simsave.mjs`（模板 GUID 2 → 8 项）

**为什么**：模拟器原来只有 `rectPrefabId=2000001`、`textPrefabId=2000002` 两个自造 GUID。
真机内置模板的实际索引是 `1073741876`（容器节点）… `1073741886`（人物），
存档里要按**真机索引**建模板，模拟器才能等价复现真机行为。现在 8 项齐全：

| 真机索引 | 元件 | 模拟器键 |
| --- | --- | --- |
| `1073741876` | 容器节点 | `containerPrefabId` |
| `1073741894` | 图片·矩形（纯色底图首选） | `rectPrefabId` |
| `1073741870` | 图片（纯色底图回退） | `imagePrefabId` |
| `1073741868` | 文本框 | `textPrefabId` |
| `1073741879` | 图片·海水 | `waterPrefabId` |
| `1073741881` | 图片·草地 | `landPrefabId` |
| `1073741883` | 图片·树木 | `treePrefabId` |
| `1073741886` | 图片·人物 | `playerPrefabId` |

### 4.3 `_tools/qxqy_mount.mjs`

**为什么**（三条独立的修复）：
1. **params 链路是断的** —— 脚本参数传不到工程里，靠 `buildParamShim` 兜底；
2. **按键注入**原来只能指定固定帧，现在支持逐键 `--key Foo@40`；帧号以引擎真实帧为准
   （默认先冻结实时钟），否则截图时机对不上；
3. **新增 `--probe-walk <帧>`**：打印控件名。这条是给「两个纯色底图模板模拟器渲染成同一张白矩形」
   准备的分辨手段 —— 只能靠控件名（`SIM_矩形` / `SIM_图片_回退`）区分，不能靠截图。

### 4.4 新增的 4 个工具脚本

- `e2e_浮岛借木.sh`：把三关解法 + A/B + 提示 + 探针 7 轮串成一条命令，
  判据是**挂载无错**与**底图模板控件总数一致**。
- `preview_art_浮岛借木.py`：**这是本轮最重要的新增工具**。
  模拟器只代理 `100001–100006` 六个图源，画不出真美术，
  所以「素材有没有严丝合缝压在格子上」必须**离线**看。它从 `config.lua` 解析调色板 /
  `ART_FIT` / 关卡数据，用与 `level.lua` **同一套几何**渲染，输出 PNG。
  ⚠️ 改 `level.lua` 的几何后必须同步它，否则它会说假话。
- `make_grass_tile.py`：⚠️ 背景是**踩过的坑** —— AI 生成图把 `grass tile` 理解成等距菱形，
  铺到正交网格上是一片菱形格纹，调参救不回来。改为**程序化生成方形顶面**，
  并内置平铺自检（格内亮度极差 < 8，防止瓦片自带渐变变成条纹）。
- `make_compare_浮岛借木.py`：生成 A/B 对照图。

## 6. 为什么这一批必须**整批**采纳（实证）

第 1 批只落了 `浮岛借木/`，共享工具链留在原处 —— 结果是
**仓库现在处于「配置与模拟器不同源」的状态，而旧校验器看不出来**：

```bash
cd <仓库根>

# 仓库现有的旧校验器：exit 0，报告"0 处不一致 / 无问题"
python _shared/_check_refs.py 浮岛借木 ; echo "exit=$?"          # -> exit=0

# 本批提交的新版校验器：exit 1，直接点出 10 处漂移
python _inbox/hzy/_shared/_check_refs.py 浮岛借木 ; echo "exit=$?" # -> exit=1
```

新版报出的 10 处（全部因为 `_sim_common.mjs` / `qxqy_simsave.mjs` 还没更新）：

```text
[索引漂移] DEFAULT_PREFAB_RECT=1073741894，但 qxqy_simsave.GUID_RECT=2000001
[索引漂移] DEFAULT_PREFAB_RECT=1073741894，但 _sim_common.rectPrefabId=2000001
[索引漂移] DEFAULT_PREFAB_IMAGE=1073741870 但 _sim_common.mjs 的 imagePrefabId 未定义
[索引漂移] DEFAULT_PREFAB_TEXT=1073741868，但 qxqy_simsave.GUID_TEXT=2000002
[索引漂移] DEFAULT_PREFAB_TEXT=1073741868，但 _sim_common.textPrefabId=2000002
[索引漂移] DEFAULT_PREFAB_CONTAINER=1073741876 但 _sim_common.mjs 的 containerPrefabId 未定义
[索引漂移] DEFAULT_PREFAB_WATER=1073741879 但 _sim_common.mjs 的 waterPrefabId 未定义
[索引漂移] DEFAULT_PREFAB_LAND=1073741881 但 _sim_common.mjs 的 landPrefabId 未定义
[索引漂移] DEFAULT_PREFAB_TREE=1073741883 但 _sim_common.mjs 的 treePrefabId 未定义
[索引漂移] DEFAULT_PREFAB_PLAYER=1073741886 但 _sim_common.mjs 的 playerPrefabId 未定义
合计 10 处
```

**结论**：`浮岛借木/config.lua`（8 项真机索引）+ `_shared/_check_refs.py`（新校验）
+ `_tools/_sim_common.mjs` / `qxqy_simsave.mjs`（8 项模板）**是一组，拆开照旧漂移**。
只采纳校验器而不采纳 `_sim_common.mjs`，`_check_refs.py` 会一直红。

> 这也解释了你在批次台账里记的「`_check_refs` 47 项 DEFAULTS 全一致」——
> 旧校验器确实全一致，它只是**不看元件索引这一块**。
