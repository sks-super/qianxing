## 4. 这是什么 / 改了什么 / 为什么

### 4.1 游戏本身（新增）

`浮岛借木` 是一个（待你定名也可）通关解谜小游戏：玩家操作一个两格高的小人，
在群岛之间**撞树、推木桩、把木桩立起来再推倒**，用木桩填掉岛屿之间两格宽的水道，
一路走到终点旗。灵感原型是《怪兽远征 / A Monster's Expedition》，
前三关布局按实机截图复刻。当前 3 关，标准解法分别 **17 / 19 / 17 步**。

挂载位置与 `割绳子` / `TickHop` 一致：客户端控件容器的「容器节点」（`script.object`）。
零配置可跑 —— 不填任何脚本参数时回退到编辑器内置模板
（容器节点 `1073741876`、矩形 `1073741894`、图片 `1073741870`、文本框 `1073741868`）。

### 4.2 本批的主要工作：地图改成 2.5D 视角

参考《怪兽远征》的截图做了改动。**先判定方向**：参考图的水面网格线是屏幕水平/垂直的、
岛缘是直角台阶，所以它**不是等距菱形投影** —— 立体感只有两个来源，都跟投影数学无关：

1. 每块陆地有厚度（顶面 → 沙滩描边 → 土壤侧面 → 落水投影）；
2. **近处一行压住远处一行**。

所以实现上**不需要旋转控件、不需要投影矩阵**，只需要一个正确的**绘制顺序**：

* **深度键** `key = band + row * 10 + sub`，`row` 是主序；
  band = `0` 网格线 / `1000` 地块装饰 / `2000` 草地顶面 / `3000` 物体与小人。
* 地形 / 物体 / 小人**必须在同一个容器**（`containerWorld`）里，否则没法用同一套
  `SetAsLastSibling` 做全局排序。容器因此从 7 个收敛到 **5 个**：
  `Bg → World → Fx → Hud → Fade`。
* `level.lua` 的 `M.restackWorld()` 按 key 升序把所有池 + 小人三件套逐个点名排序；
  **小人换行后要再排一次**（key 含行号，换行会翻转遮挡关系）。

新增可调参数（`config.lua` 的 `DEFAULT_*`，`编辑器.html` 的 `DEFAULTS` 逐项镜像）：
`DEFAULT_VIEW_25D` / `TILE_SIDE_RATIO` / `TILE_RIM_RATIO` / `TILE_SHADOW_ALPHA` /
`TILE_FOOT_RATIO` / `OBJ_SHADOW_ALPHA` / `WATER_GRID_LINES` / `WATER_LINE_ALPHA`。

### 4.3 美术素材

4 张素材由 AI 生成 + 本地抠图去水印得到，配 `config.lua` 的 `DEFAULT_ART_FIT`
（素材内容占比 → 控件缩放系数）严丝合缝压在格子上。
**草地**那张是**程序化生成**的：AI 出图会把「grass tile」理解成等距菱形视角，
铺到正交方形网格上就变成一片菱形格纹（数量级问题，调参救不回来）。

⚠️ 一个必须保留的约定：**美术素材元件一律不写 `imageColor`** —— 它是 `AARRGGBB`
**乘法染色（tint）**，会把美术乘暗/串色。素材拿不到控件时当场降级成通用矩形 + 调色板染色，
保证任何路径都不会出现整片空白。
