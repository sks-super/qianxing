# 2026-10-18 · 点灯迷题 2D 重制

## 做了什么

新建 `点灯迷题2D/`（14 个 `.lua` + `README.md`），把「客户端只做 UI + 3D 棋盘在节点图」
的旧版重做成**纯客户端 2D**：棋盘、玩法、判定、动效全部在 Lua 里，不再需要节点图。

- `board.lua`：5×6 灯阵模型。核心是**剩余解 = flips 集合 XOR 已按集合**
  （按压可交换 + 对合）→ 提示与星级都是精确的，不用解线性方程组。
- `anim.lua` / `utils.lua`：直接从 `2048_景苏` 移植（补间引擎 + 真机坑的控件工具）。
- `view.lua`：横向**翻牌**（X 轴压到 0.045 再展开）、十字五格**按距离错峰**、
  光晕**呼吸**（20fps 刷新，剩 ≤3 盏加剧）、方形冲击波、照片态。
- `fx.lua`：粒子 / 轻烟 / 方形冲击波（四条边）/ 飘字 / 彩带 / 震屏。
- `menu.lua`：50 关分页选关（5×4/页，星级，错峰入场）。
- `winUI.lua`：棋盘缩成「战利品照片」飞左，结果卡右滑入，三星逐颗弹出，步数滚动。
- 50 关数据由 `点灯迷题/_levels.json` 用脚本转成 `M.LEVELS`（含 tip）。

## 踩到的坑（都已修）

1. **`state.lua` 必须写成 `M.xxx = ...`**：`_check_refs.py` 只认 `M.(\w+)\s*=` 与行首赋值，
   写 `state.xxx = ...` 会被判成「383 处未定义」。
2. **`getParamNumber` 必须是全局函数**：模拟器的参数兜底是「在入口脚本末尾覆盖全局
   `getParamNumber`」；写成 `local function` 就覆盖不到 → 本地试玩一直报「请设置 rectPrefabId」。
3. **先翻转逻辑再重建视图会吃掉翻牌动效**：视图必须拿「按下前」的盘面 `snap`，
   否则待翻的 5 格已经是终态色，翻牌看不出变化。→ `view.playPress(idx, bd, { prev = prev })`。
4. **`anim.delay` 注册的开发钩子会被 `buildLevel` 的 `clearAll()` 清掉** →
   改由 `OnUpdate` 按时间触发（`autoPress`）。
5. 每个灯格的闪光/高光要用**独立 tag**（`view:fx:<idx>`），否则 A 格翻牌会掐掉 B 格的动画。
6. 翻牌时不要再叠一条「下压回弹」补间：两段同时写 scale 会打架。

## 二次改造：16×16 勾线版（进行中）

### 算出来的关键事实（不是拍脑袋）
- **16×16 十字核：秩 248，零空间 8 维** → 同一盘面 **256 组等价解**，唯一解做不到。
- **最优步数可精确算**：特解 + 枚举 256 个零空间向量取最小重量。关卡生成时离线算好写进数据。
- **可读性阈值（实测扫图）**：|A|=4 清楚 / 6 可辨 / 8 勉强 / **12 已认不出 / 16 纯噪声**
  → 模式一 |A| ≤ 6；模式二可不限（不依赖图案）。

### 像素画

  与 64 彩色（4× 精度重绘 + 分区上色 + 纵向明暗 + 2px 描边）。
- 产物：`_art/out/sheet_16.png` / `sheet_64.png` / `demo_puzzle.png` / `demo_sweep.png`。
- 踩坑：① 细线（花茎）若正好落在像素缝隙里会整条消失 → 线宽 ≥1.1 或对齐像素中心；
  ② 只取「并集外轮廓」会把头/身/翅边界全吞掉，16px 上认不出 → 必须**逐形体取轮廓**；

### ★ 结构澄清（用户）：4 个 8×8 是**四个独立关卡**，共同组成大关卡

- 大关 = 一张 16×16 图 → 拆 左上/右上/左下/右下 四个 8×8 小关，每块单独玩，4/4 才演出。
- **8×8 十字核满秩（64/64，零空间 0）→ 每块解唯一**；16×16 秩 248/零空间 8 → 256 组解。
  ⇒ 拆开反而**把数学问题变简单**：最优步数 = |A|，不用求特解+枚举零空间，星级可直接按 |A| 给。
  （n=5 秩23 / n=6,7,8,10 全满秩 / n=16 秩248 —— 已实测）
- 8×8 可读性：|A|≥3 象限就明显走形（线条本来就少）→ **左侧参考图是必需项**，
  「找不同」只是入场引导，真解法是「按下去翻哪 5 格」的推理。
- 演出分两级：小关完成 → 缩成拼图块飞进顶部 2×2 槽（"咔哒"落位）；
  4/4 → 分离再合拢 → 描边发光 + 粒子汇聚 + 色彩沿线条流入 → 64×64 交叉淡入。

### 本轮三个「不报错但画面全错」的坑
1. **`applyLayerOrder` 只传部分控件 = 把底板提到最上层**：白纸盖住 64 个格子 →
   棋盘一片白；256 格上色面板同样一片空。**必须一次传全层**（底 → … → 顶）。
2. **容器偏移叠加两次**：`containerBoard` 放到棋盘中心 + 内层容器又放到棋盘中心 → 棋盘飞出屏幕。
   震屏只动 `containerBoard`，内层容器必须归零。
3. **通关判定比错对象**：一维 `board` vs 二维 `quad`，`board.equals` 逐项取到 nil → 永远 false
   （表现：步数到了、盘面看着对了，但没反应）。
