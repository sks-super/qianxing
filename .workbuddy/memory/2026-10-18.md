# 2026-10-18 · 点灯迷题 2D 重制

## 做了什么

新建 `点灯迷题2D/`（14 个 `.lua` + `README.md`），把「客户端只做 UI + 3D 棋盘在节点图」
的旧版重做成**纯客户端 2D**：棋盘、玩法、判定、动效全部在 Lua 里，不再需要节点图。

- `board.lua`：5×6 灯阵模型。核心是**剩余解 = flips 集合 XOR 已按集合**
  （按压可交换 + 对合）→ 提示与星级都是精确的，不用解线性方程组。
- `anim.lua` / `utils.lua`：直接从 `2048_景苏` 移植（补间引擎 + 真机坑的控件工具）。
- `view.lua`：横向**翻牌**（X 轴压到 0.045 再展开）、十字五格**按距离错峰**、
  光晕**呼吸**（20fps 刷新，剩 ≤3 盏加剧）、方形冲击波、照片态。
- `fx.lua`：粒子 / 轻烟 / 方形冲击波（四条边）/ 飘字 / 彩带 / 震屏。
- `menu.lua`：50 关分页选关（5×4/页，星级，错峰入场）。
- `winUI.lua`：棋盘缩成「战利品照片」飞左，结果卡右滑入，三星逐颗弹出，步数滚动。
- 50 关数据由 `点灯迷题/_levels.json` 用脚本转成 `M.LEVELS`（含 tip）。

## 踩到的坑（都已修）

1. **`state.lua` 必须写成 `M.xxx = ...`**：`_check_refs.py` 只认 `M.(\w+)\s*=` 与行首赋值，
   写 `state.xxx = ...` 会被判成「383 处未定义」。
2. **`getParamNumber` 必须是全局函数**：模拟器的参数兜底是「在入口脚本末尾覆盖全局
   `getParamNumber`」；写成 `local function` 就覆盖不到 → 本地试玩一直报「请设置 rectPrefabId」。
3. **先翻转逻辑再重建视图会吃掉翻牌动效**：视图必须拿「按下前」的盘面 `snap`，
   否则待翻的 5 格已经是终态色，翻牌看不出变化。→ `view.playPress(idx, bd, { prev = prev })`。
4. **`anim.delay` 注册的开发钩子会被 `buildLevel` 的 `clearAll()` 清掉** →
   改由 `OnUpdate` 按时间触发（`autoPress`）。
5. 每个灯格的闪光/高光要用**独立 tag**（`view:fx:<idx>`），否则 A 格翻牌会掐掉 B 格的动画。
6. 翻牌时不要再叠一条「下压回弹」补间：两段同时写 scale 会打架。

## 模拟器验证（已跑通）

```bash
export NODE_PATH="$HOME/.workbuddy/binaries/node/workspace/node_modules"
node _tools/qxqy_mount.mjs --game 点灯迷题2D --entry game.lua \
  --preset sim --open _simulator/sim-ready.save.json --mount n1 \
  --params '{"cursorPrefabId":2000001,"autoStart":1,"autoPress":19}' --steps 135
```

- `--preset sim` 给模板 GUID；`--open _simulator/sim-ready.save.json` + `--mount n1` 才能挂上容器。
- 实测：选关 → 进关 → 翻牌 → 全灭判定 → 通关动效 → 结算面板，日志零报错。
- 截图里偶尔出现的「文本 / 白色大星 / 蓝色横条」是**就绪存档自带的模板节点**，不是本工程控件。
