- 本次列举的 7 项 API 重命名中，项目代码**实际会报错**的只有一处：
  - `game.lua:456` `script:EnableTick(true)` → 改为 `script:EnableUpdate(true)`（方法 `EnableTick` 已在新版更名为 `EnableUpdate`）。已修复，块平衡 74/74 OK。

  - `GetScript` 参数 `scriptPrefabId→scriptMappingId`：本项目未调用 `GetScript`。
  - `itemPrefabId→itemPrefabIndex` / `referencedPrefabId→referencedPrefabIndex`：未使用对应控件。
  - `ClientUIBaseControl.prefabId→prefabIndex` / `Script.prefabId→scriptMappingId`：代码中从未读取这两个运行时字段。
- 重要约束：`fruitPrefabId` / `starPrefabId` / `bladePrefabId` 是**编辑器脚本变量绑定名**（经 `getParamNumber("fruitPrefabId",0)` 读取），其 `prefabId` 后缀**不能改名**，否则读不到配置值。代码中其余 `prefabId` 均为自有变量名/数据字段，非运行时 API 字段，保持原样。
