**进果园 = 天空向上移出屏幕、地面向下移出屏幕；返回选关反之（天空从上进、地面从下进），0.5s 左右。**

### 实现（`transition.lua` 整篇重写，435 行）
只留两种转场：`fade`（黑幕，重玩 / 关内换片）+ `split`（天地撕开，选关 ↔ 游玩）。
`split` 用两块**风格化的板**（不是截图，引擎没法把 containerScene 切一半）：
上半 = 三段天光 + 3 团云 + 远丘/近丘（混天空色做空气透视）+ 6 个远处树点 + 底部「纸厚度」边；
下半 = 草底 + 受光草坡 + 6 组小草 + 落果 + 石子 + 顶部深绿边。

- `mode="open"`（0.42s）：板已合拢 → **第 0 帧就切屏**（onPeak 在 play 里同步执行）→
  天空 y:+H/4 → +(0.75H+52)，地面镜像；easeInOutCubic + `scaleY=1+0.035sin(πk)` 轻微拉长。
- `mode="close"`（0.24+0.04+0.16）：从屏外滑入合拢（easeOutCubic，冲进来贴住）→ 切屏 →
  逐控件 alpha 淡出（构造时把 `(句柄,原色)` 记进 list）。
- game.lua：enterLevel 按 `state.screen ~= "play"` 分流（地图进 = split open；结算里换片 = fade），
  backToSelect / onServerSelect = split close；删掉 TRANS_CYCLE / pickTransition。
- config：删 `DEFAULT_TRANS_SLIDE_*/FRUIT_*/RIBBON_*`，加 `DEFAULT_TRANS_SPLIT_OPEN/_MERGE/_FADE`。

### 坑

   否则会溢出盖到屏幕另一半（画"贴底的山"用「圆心 y=-hh+半径」实现）。
