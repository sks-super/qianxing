# 点灯迷题 16 · 千星奇域客户端 Lua 工程

> **16×16 勾线画 → 拆成 4 个 8×8 小关 → 4/4 合拢 + 上色演出**。
> 纯客户端 2D，不依赖服务器节点图。

---

## 一、玩法结构

```
大关（一张 16×16 黑白勾线图）
├─ 小关 1  左上 8×8
├─ 小关 2  右上 8×8
├─ 小关 3  左下 8×8
└─ 小关 4  右下 8×8
4/4 完成 → 四块合拢成 16×16 → 逐格上色
```

- 点一格：**自身 + 上下左右**共 5 格一起黑白翻转（越界只翻存在的）。
- 左侧是目标图案 P，右侧是当前盘面 S；把 S 还原成 P 即通关。
- 每个小关独立结算，顶部四个拼图槽显示进度（完成一块亮一颗 ★）。

### 为什么拆成 8×8 很关键

| 棋盘 | 格数 | 核的秩 | 零空间 | 解数 |
| --- | --- | --- | --- | --- |
| 5×5 | 25 | 23 | 2 | 4 |
| **8×8** | **64** | **64** | **0** | **1（唯一）** |
| 16×16 | 256 | 248 | 8 | 256 |

**8×8 满秩 ⇒ 每个小盘的解唯一**，于是：

- 答案唯一，不会被"另一条路"判错；
- **最优步数 = |A|**，不用解方程；
- 星级：`步数 == |A|` → ★★★，`≤ |A|+2` → ★★，通关 → ★。

## 二、两种模式

| 模式 | 目标 | 说明 |
| --- | --- | --- |
| 找不同（默认） | 右侧还原成左侧 P | 左参考图常驻；差异高亮只作引导，不是答案 |
| 无参照 | 右侧变全白 | 隐藏左图，`S = R(A)`，点回空白即通关 |

> 十字规则下「差异格」**不等于**「该点的格」，所以找不同模式的提示分两级：
> ① 差异高亮（告诉你哪里不一样）② 提示一格（给出 A⊕B 里的一个真解点）。

## 三、动效

| 场景 | 效果 |
| --- | --- |
| 点击 | 该格横向压扁 → 展开（翻牌，中点换色）+ 方形冲击波 + 轻微震屏 |
| 涟漪 | 十字五格按「距中心远近」错峰 30ms 依次翻 |

| 小关完成 | 拼图槽亮一颗 ★ + 弹跳；0.85s 后黑幕切到下一块 |
| 通关演出 | 256 格从黑/白逐格渐变到主色/辅色/高光色（按白区连通分区，从上到下分配）+ 彩带 |
| 提示 | 该格绿色脉冲 1.2s + 一圈冲击波 |

## 五、装配

| 参数 | 元件 | 必填 |
| --- | --- | --- |
| `rectPrefabId` | 纯色矩形（图片控件） | ★ 棋盘 / 面板 / 按钮全靠它染色 |
| `textPrefabId` | 文本框 | ★ |
| `cursorPrefabId` | 光标检测区域 | ★ 没有它鼠标点不动 |
| `containerPrefabId` | 容器节点 | 可选。配了就用**真容器**当父节点（模拟器里必须配，见下） |

音效可选：`flipAudioId` / `clickAudioId` / `winAudioId` / `starAudioId`。
把 `game.lua` 挂到**客户端控件容器的容器节点**上。

> **为什么要 `containerPrefabId`**：原来用纯色矩形（图片控件）当父节点也能正常显示，
> 但模拟器的命中测试只下钻 `container / grid / textwindow / reference / button` 这几种 kind，
> 图片当父节点时**所有子控件的点击都不可达**（真机不受影响）。配了真容器就一致了。

### 开发用参数（正式不传）

| 参数 | 作用 |
| --- | --- |
| `autoStart` | 1 = 跳过开场直接进第 1 块 |
| `autoSolve` | 1 = 自动按 A 解题，用于跑穿 4 块看通关演出 |
| `autoPress` | 填 0..63，1 秒后自动按一格 |

## 八、已知边界

- **网页模拟器的点击已打通**（2026-10-19）。之前「点哪都没反应」的真因是
  **挂载节点的矩形退化成中心一个点**：模拟器命中测试要求「点落在每一层祖先的矩形内」才继续下钻，
  而挂载节点默认锚点居中、尺寸为 0 → 所有子控件不可达。`qxqy_websave.mjs` 的
  `buildCursorShim()` 现在会在 `OnStart` 前把挂载节点规整成铺满画布（锚点 0,0→1,1，size 0）。
  实测：8×8 棋盘逐格点击全部命中，步数逐个递增。
- 命中区比格子大一圈（+5px 间隙），整块棋盘无缝可点。

- 上色是**纯 Lua 的 16×16 色块版**（路径 B），还不是 64×64 精细画。
  要真 64×64，需要把 `_art/out/64/*.png` 上传成千星图片资源，再用一个图片控件淡入。
- 没有关卡选择界面（换大关按钮在两个大关之间循环）。
- 小关顺序固定为「通关后自动跳下一块」，未做自由选择。
