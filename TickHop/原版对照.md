## 3. 坐标换算

原版画面 1280×720，工程世界 800×600（原点居中、Y 向上为正）：

```
world_x = (px - 639.5) * 0.625
world_y = (360   - py) * 0.625
```

0.625 = 800 / 1280，等比缩放不做拉伸；纵向 720×0.625 = 450，居中后落在 y ∈ [-225, 225]。

## 5. 跳跃参数：实测与反推

### 实测
- 用 `_tools/orig_jump.mjs`（时间均值背景差分 + **双眼定位**）逐帧追踪玩家。
  眼睛是身体内部固定参考点，可绕开「玩家头顶永远跟着倒计时数字」「圆角处露出背景」两类污染。
- 官方短片 100 fps 封装但**有效帧率仅约 20 fps**、码率 94 kbps，跳跃中段常跟丢，
  因此**无法精确拟合抛物线**；只能得到量级。
- 可交叉印证的量级：
  - 短片 c1 一次满跳上升 ≈ 122 px（≈ 2.5～3 个身位），上升 ≈ 0.18 s；
  - 第02关**关卡本身要求**一次上升 240 px（≈ 3.2 个身位）、水平 290 px。
- 玩家身位：原版 1280×720 下约 58×75 px；工程 34×44 px，**长宽比一致（0.773）**，说明工程角色是照原版比例做的。

### 反推（已写入 config.lua）
| 量 | 原版量级 | 工程取值 |
|---|---|---|
| 跳高 H | ≈ 3.2～4.0 个身位（≥150 px 硬约束） | v²/(2g) = **175 px** = 3.98 个身位 |
| 上升耗时 | ≈ 0.18～0.24 s | v/g = **0.242 s** |
| 水平全距 | ≈ 4.5 个身位 | 520 × 0.463 = **240 px** |

| 参数 | 旧值 | 新值 |
|---|---|---|
| `DEFAULT_MOVE_SPEED` | 260 | **520** |
| `DEFAULT_GROUND_ACCEL` | 2600 | **7000** |
| `DEFAULT_GROUND_FRICTION` | 3200 | **9000** |
| `DEFAULT_AIR_ACCEL` | 1500 | **4500** |
| `DEFAULT_AIR_FRICTION` | 300 | **900** |
| `DEFAULT_JUMP_SPEED` | 520 | **1450** |
| `DEFAULT_GRAVITY` | 1600 | **6000** |
| `DEFAULT_FALL_GRAVITY_MULT` | 1.35 | **1.20** |
| `DEFAULT_MAX_FALL_SPEED` | 1000 | **1800** |

> 编辑器 DEFAULTS 同步即可整批回退。

## 6. 跳跃触发语义（已实现）

原版是「松手即停」，工程原先存在「按住会连跳」的引擎按键重复问题。已改为：

- `DEFAULT_JUMP_EDGE_TRIGGER = 1`：**只在按下的那一刻触发一次**，按住不会连跳；
- `DEFAULT_JUMP_CUT_MULT = 0.45`：松手截断（**只截断一次**）→ 轻点小跳 / 长按高跳；
- 落地前提前按下 → 缓冲到**落地那一刻**才起跳（`DEFAULT_JUMP_BUFFER_TIME = 0.12`）。

验证：`node _tools/verify_jump.mjs`，4 个用例全过（按住连按 120 次只跳 1 次；轻点顶点 51 px /
长按 82 px（旧参数下）；空中提前按下 → 二次起跳距地面 0 px）。

## 7. 前 3 关可行性核算

`node _tools/check_jump_feasible.mjs` —— 用与 `physics.lua` **完全相同**的积分/碰撞代码模拟满跳：

```
第01关  出生点落在地面 top=-189，门底同样落在地面      → 走路即可
第02关  出生点落在上层地面 top=-107，门在 top=43
        →右 从 top=-107 x=-88 起跳 可落到 top=43        ✓
第03关  出生点落在左平台 top=-12，门在右平台 top=-12
        →右 从 top=-12 起跳 可落到 [tick5] top=-6        ✓
        →右 从 top=-6 起跳 可落到 top=-12（右平台）      ✓
```

## 8. 复刻时对工程的取舍

1. **保留教学文本**：原版无文本，工程每关保留一句提示（用户要求保留）。
2. **边框即墙体**：原版的白框既是墙也是地面，工程把它拆成 4 块 `tick = -1` 的永驻平台，
   外观与碰撞都对应。
3. **配色**：`bg=000000 / platform=FFFFFF / ghost=B4B4B4 / label=labelGhost=111114`
   （原版熄灭态是浅灰平台 + 深色数字，两态同为深色标签）。
4. **第02关的下沉台阶**：原版是一整块连通白区；工程按矩形拆分，台阶顶面略低于上层地面 5 px
   以避免 AABB 互相挤压。掉进下层是死路（与折线走廊设计一致）。
